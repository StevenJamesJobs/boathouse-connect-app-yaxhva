Shared buildEvery sheet here is GlassSheet; tiles are the Tools-kit tinted glass; the seg is menu-upload's; rows are MenuSheet's. New shared pieces: ScheduleGearChip · ScheduleNavSheet · ScheduleUploadSheet · ScheduleSettingsSheet · ShiftEditSheet · ShiftRow · AvailableShiftCard · DecisionBlurb · ApprovalCard.
Attention storyManager: push → shade row → Schedule-tab dot + AttentionRing on the clock tab → Approvals tile pulse + count. Employee: push → shade row (only them) → tab dot + ring → DecisionBlurb. Seeing any one clears all (one RPC: ack_schedule_decisions).
Rules baked inA manager never decides their own request (server + disabled buttons). Pick-ups are title-matched server-side. Deny on a pick-up re-opens the shift. Releases need no approval. Toggles hide surfaces; the server enforces regardless.
