The locked modalGlassSheet (88% max, pinned title + rail + footer, the shrinkable-scroll pair). Steps: Announcements Basics · Details · Extras · Review; Specials + Events add When. Rail = done ✓ / current / upcoming with the progress line; rail taps and Review lines jump anywhere. Footer = Cancel|Next → Back|Next → Back|Post. Edit mode opens the same sheet on Review with every step ✓, so a quick fix is one tap deep.
Review = preview + linesUnder the rail sits the exact Welcome-tab card (thumb, title, NEW pill, 2-line body, date/badge line, attachment glyph) inside a glass frame with a mono eyebrow saying WHERE it lands. Below it the per-step lines; gaps read ember. Notify staff lives here, create-only.
AttachmentsExtras offers two tiles: From Guides & Training (opens the grouped picker sheet) or Upload a file (PDF/image, one-time). A guide link stays in Guides when the post goes; a one-time upload is deleted with the post — on manual delete AND on auto-expiry. Server: one nullable attachment column + name per table (additive), a new broker purpose per content type, and the expiry sweep returning the URLs it retired so the client can broker-delete them (SQL can't touch storage).
Editor page + ⋯Unchanged from round 1 except the ⋯ sheet is back to the canonical five rows — visibility stays a field in Extras (Announcements only). Cap counter 25 · 25 · 100, all client-side.
